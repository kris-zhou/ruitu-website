# 瑞途（香港）贸易有限公司官方网站

## 项目概述

瑞途（香港）贸易有限公司是一家专注于跨境美妆批发和贸易的企业。本项目是公司的官方网站，旨在展示公司形象、产品服务、业务流程以及提供在线联系方式，满足客户了解公司和产品的需求。

网站提供三种语言版本（中文、英文和韩文），支持响应式设计，适配桌面端和移动端访问。

## 技术架构

### 前端技术栈
- **HTML5**: 网站结构
- **CSS3**: 样式与动画效果
- **JavaScript**: 交互功能和动态效果
- **Bootstrap 5.3**: 响应式布局框架
- **Font Awesome 6.0**: 图标库

### 代码组织
项目采用静态网站架构，无后端服务器依赖，主要通过以下方式组织代码：
- 模块化CSS
- 功能性JavaScript组件
- 多语言版本分离

### 部署方式
网站采用静态部署方式，支持通过Netlify等静态托管服务部署。

## 主要功能

### 1. 多语言支持
- 中文版：面向中国大陆市场
- 英文版：面向国际市场
- 韩文版：面向韩国市场

### 2. 内容模块
- **首页轮播图**: 展示公司形象和主要产品
- **公司介绍**: 展示公司背景和核心价值观
- **关于我们**: 详细介绍公司历史和发展
- **合作品牌**: 展示与公司合作的知名品牌
- **产品展示**: 介绍公司主营产品和服务
- **业务优势**: 突出公司的核心竞争力
- **业务流程**: 说明合作流程和步骤
- **正品保证**: 强调产品质量保障
- **物流与仓储**: 介绍物流服务和仓储能力
- **联系我们**: 提供多种联系方式和在线留言

### 3. 交互功能
- **导航菜单**: 固定顶部导航，支持响应式折叠
- **平滑滚动**: 点击导航链接平滑滚动到对应位置
- **返回顶部按钮**: 快速回到页面顶部的悬浮按钮
- **语言切换**: 一键切换不同语言版本
- **图片放大**: 支持点击查看大图功能
- **联系表单**: 提供在线留言功能

### 4. 响应式设计
- **桌面端优化**: 提供完整内容展示和交互体验
- **平板端适配**: 调整布局和元素大小
- **移动端适配**: 优化导航和内容排版，确保在小屏幕设备上的良好体验

### 5. 性能优化
- **图片优化**: 压缩图片大小，提高加载速度
- **懒加载**: 图片资源按需加载
- **CSS优化**: 结构化的CSS，减少冗余代码
- **浏览器兼容**: 支持各主流浏览器，包括Safari、Chrome、Firefox和Edge

## 安装与部署

### 本地开发
1. 克隆仓库到本地:
```bash
git clone https://github.com/kris-zhou/ruitu-website.git
cd ruitu-website
```

2. 使用任意Web服务器启动项目，如使用Python的简易HTTP服务器:
```bash
# Python 3
python -m http.server

# Python 2
python -m SimpleHTTPServer
```

3. 打开浏览器访问 `http://localhost:8000` 即可查看网站

### 线上部署

#### 通过Netlify部署
1. 在Netlify上创建新站点
2. 连接到GitHub仓库
3. 设置部署选项：
   - 构建命令: 不需要
   - 发布目录: /
4. 点击部署按钮

#### 通过其他静态网站托管服务
项目可以部署到任何支持静态网站托管的服务上，如GitHub Pages、Vercel、AWS S3等。
