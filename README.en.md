# ruitu_website

#### 公司网站描述
   瑞途（香港）贸易有限公司是一家专注于跨境美妆批发和贸易的公司。我们致力于为全球客户提供高品质的美妆产品，包括化妆品、护肤品、香水等。 
   这个网站是瑞途（香港）贸易有限公司的官方网站，主要用于展示公司产品、提供在线批发服务、以及与客户进行沟通和交流。


#### 软件架构
软件架构描述  
    这个网站使用HTML、CSS和JavaScript等前端技术开发，并结合了Bootstrap框架来实现响应式设计。
    后端使用Node.js和Express框架来处理请求和数据处理。
    数据库使用MySQL来存储产品信息和客户数据。
